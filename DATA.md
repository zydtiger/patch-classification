## Data Structure

├───data
│   └───NCT-CRC-HE-100K
│       ├───ADI
│       ├───BACK
│       ├───DEB
│       ├───LYM
│       ├───MUC
│       ├───MUS
│       ├───NORM
│       ├───STR 
│       └───TUM

Each folder in 'NCT-CRC-HE-100K' is the label (e.g. ADI for adipose tissue), and within each folder, we have *.tif RGB H&E images of size 224x224.
